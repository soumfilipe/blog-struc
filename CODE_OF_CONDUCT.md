# Código de conduta

Este é o repositório do site pessoal de Filipe Costa. Ele aceita issues e pull requests de qualquer pessoa, e quem participa precisa seguir estas regras. Elas valem para issues, pull requests, comentários e qualquer outro espaço ligado ao projeto.

## O que se espera

- Tratar todas as pessoas com respeito, inclusive quando discordar delas.
- Criticar ideias, código e textos, nunca as pessoas.
- Aceitar que nem toda sugestão vai ser aceita. Este é um site pessoal, e a decisão final é do autor.
- Escrever de forma clara e direta, pensando em quem vai ler.

## O que não é aceito

- Ofensas, xingamentos ou ataques pessoais.
- Discriminação ou assédio por gênero, identidade de gênero, orientação sexual, raça, etnia, origem, classe, religião, deficiência, idade ou aparência.
- Discurso de ódio, conteúdo sexual ou violento sem relação com o assunto.
- Divulgar dados pessoais de outras pessoas sem autorização (endereço, telefone, documentos e afins).
- Insistir em contato depois de alguém pedir para parar.
- Spam, propaganda ou uso do repositório para promover produtos e serviços.

## Como denunciar

Escreva para [ola@filipecosta.eti.br](mailto:ola@filipecosta.eti.br) contando o que aconteceu, onde e, se possível, com links. A denúncia é tratada com sigilo.

## O que acontece

Dependendo da gravidade, o autor pode editar ou apagar comentários, fechar issues e pull requests, ou bloquear a pessoa no repositório, com ou sem aviso prévio.

Este código se inspira no [Contributor Covenant](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).
